# .sh_ai — personal AI assistant (integrated app)

Окремий застосунок усередині портфоліо. Живе за адресою **`example.com/sh_ai`**
(локально `http://localhost:8787/sh_ai`).

> Роут лишено `/sh_ai`: Astro не роутить dot-шляхи (файли/папки з крапкою ігноруються).

## Структура (самодостатня, готова до переїзду в окремий репозиторій)

```
apps/.sh_ai/
├── README.md
├── App.astro              # повний UI: Sidebar + чат (фрагмент, без <html>)
├── strings.ts             # власні UI-рядки (10 мов) — жодних імпортів з хоста
├── components/ui/         # shadcn-порти: Button, Badge, Avatar, Skeleton (+Separator, Switch про запас)
├── scripts/
│   ├── chat-core.ts       # ядро: провайдери, SSE-стрімінг, файли/vision, TTS — без DOM, без персоналки
│   └── chat-page.ts       # UI-логіка: сесії, сайдбар, композер, голос
└── styles/chat.css        # shadcn-токени + Sidebar (collapsible="icon") + бульбашки, монохром
```

Додаток повністю standalone: жодної інформації про власника ні в HTML, ні в JS-бандлі.
Запит завжди йде як general AI (`provider: auto`, `siteContext: ''`).

## Точки інтеграції з хостом (що замінити при переїзді)

1. **Роут** — `src/pages/sh_ai.astro` (тонка обгортка: layout + `<App/>` + script).
   В окремому репо це стане `src/pages/index.astro`.
2. **Layout** — `src/layouts/Base.astro` дає `<head>`, монохромні SVG-іконки (`Icons.astro`),
   тему `body.dark`. В окремому репо — свій layout + свої іконки.
3. **Дані** — жодних. `strings.ts` покриває весь UI-текст. В окремому репо нічого міняти не треба.
4. **API** — `/api/chat`, `/api/models`, `/api/health` (Vercel functions у `api/`,
   ключі ТІЛЬКИ з `.env`: `OPENROUTER_API_KEY`, `GROQ_API_KEY`,
   опційно `OPENROUTER_MODEL` / `GROQ_MODEL`).
   В окремому репо — скопіювати папку `api/` цілком.
5. **Дані** — жодних. `strings.ts` покриває весь UI-текст. В окремому репо нічого міняти не треба.

## Топбар (завжди зверху, без ліній)

- Зліва: вибір режиму Flash / Deep / Uncensored (у привітальному і в поточному чаті на місці)
- Справа: кнопка теми (темна → світла → авто, іконка показує поточний режим)

## Золоті непорушні правила (зашиті в `api/_lib.js` + `chat-core.ts`, діють у всіх режимах)

1. Ім'я — **.sh_ai**, розробник — **serhord.dev**. Ніколи не називатись інакше.
2. Мова відповіді = мова, якою пише юзер просто зараз. Перемкнувся посеред чату — відповідь одразу новою мовою.
3. Коротко і точно, без води.
4. Є важливі доповнення — не вивалювати, а коротко запропонувати роз'яснити.

## Режими моделей

- **Flash** → швидкий режим (`GROQ_API_KEY`, `GROQ_MODEL` у `.env`)
- **Deep** → глибокий режим, робоча модель підтягується з `/api/models` автоматично
- **Uncensored** → твоя Ollama на приватному сервері (дані тільки у `.env`)

Все ключі/URL — ТІЛЬКИ в `.env` на сервері, у фронтенд нічого не тече.
Користувач бачить лише назви режимів. Історія чатів завжди зберігається локально (localStorage).

## Функціонал

- Gemini-стиль: старт завжди з центрованого привітання (щоразу різне, typewriter) і полем вводу під ним;
  при відправці привітання анімовано йде вбік, повідомлення розкладаються (своє — вправо, відповідь — вліво), ввод докується вниз
- Старт завжди чистий: минулі чати тільки в історії сайдбара, порожні чернетки в історію не пишуться
- Sidebar: зверху тригер → пошук по історії → кнопка «Новий чат», далі тільки чати, нуль налаштувань; згортання в icon-rail (десктоп), offcanvas (мобайл), Ctrl+B
- Сесії в localStorage (створити/видалити/лічильник/пошук)
- Стрімінг SSE + non-stream fallback, stop-кнопка, `via`-атрибуція
- Файли (txt/md/pdf/код до 4MB → текст) + vision (зображення → 1024px JPEG)
- Голосове введення (SpeechRecognition) + озвучка відповіді на бульбашці
- Дії на бульбашці (вирівняна монохромна пігулка): копіювати, озвучити, перекласти,
  детальніше (досилає уточнення в чат), повторна генерація (тільки на останній відповіді)
- Експорт чату в буфер, typing-індикатор
